# PbTactical

**Videojuego de disparos tácticos multijugador de código abierto**

PbTactical es un videojuego independiente de disparos tácticos en primera persona (FPS), desarrollado con Godot 4 y C#.

El objetivo del proyecto es ofrecer una experiencia competitiva inspirada en los FPS tácticos clásicos, con movimientos precisos, mecánicas de disparo basadas en la habilidad, servidores dedicados y un desarrollo abierto a la comunidad.

## Características previstas

- Partidas competitivas multijugador de hasta 5 contra 5.
- Servidores dedicados para Windows y Linux.
- Sistema de red con servidor autoritativo.
- Modos de juego por rondas.
- Sistema económico para comprar armas y equipamiento.
- Modo de colocación y desactivación de explosivos.
- Armas con retroceso, dispersión y patrones de disparo.
- Mapas originales diseñados para partidas competitivas.
- Partidas privadas con amigos.
- Sistema de espectadores y marcador.
- Servidores configurables por la comunidad.
- Compatibilidad con Docker y Pterodactyl.
- Herramientas para desarrollar contenido adicional.

## Objetivos del proyecto

1. Crear un videojuego táctico totalmente independiente.
2. Ofrecer una experiencia multijugador fluida y competitiva.
3. Permitir alojar servidores privados sin depender de servicios oficiales.
4. Facilitar la personalización de mapas, modos de juego y servidores.
5. Mantener el código fuente disponible públicamente.
6. Fomentar la participación de la comunidad.

## Estado del desarrollo

**Versión prevista:** 0.1.0-alpha

**Estado:** planificación y desarrollo inicial.

La primera versión jugable tendrá como objetivo permitir partidas privadas entre varios jugadores, con movimiento, disparos, sistema de daño y un servidor dedicado funcional.
